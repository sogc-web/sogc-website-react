# SOGC Admin

Admin scaffold for the Society of Global Cycle project.

## Stack

- React
- Vite
- Tailwind CSS
- React Router

## Start

1. Run `npm install` inside `Admin`
2. Run `npm run dev`

## Notes

- Current auth is a placeholder in `src/layouts/AdminLayout.jsx`
- The login page is UI-only until the Node/Express backend is wired
- Page shells match the roadmap scope: Admins, Events, Gallery, and Popup
